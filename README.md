# green_corridor
### **Project Description: GreenCorridor AI**

**GreenCorridor AI** is a smart urban traffic management system designed to eliminate emergency vehicle delays at congested intersections.

* **The Challenge:** In crowded cities, ambulances and fire trucks lose critical time waiting at red lights and stuck in static traffic jams.


* **How It Works:** The system tracks the live GPS location of an dispatched emergency vehicle in real time. When the vehicle gets within a set distance (e.g., 500 meters) of an intersection, the system dynamically overrides the signal to turn **GREEN**, clearing traffic before the emergency vehicle arrives.


* **The Impact:** It turns red signals into automated "green waves," cutting emergency response times by 30%–50% to save lives during critical situations.
